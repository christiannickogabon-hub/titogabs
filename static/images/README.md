Place the municipality logo image here so the site can use it as a faded background.

- Save a local copy as: `static/images/logo.png` (optional).
- This project currently uses the Wikimedia-hosted image as the background by default:
	`https://upload.wikimedia.org/wikipedia/commons/6/69/Carigara%2C_Leyte_Official_Seal.png`
- License: CC BY-SA 4.0 — if you reuse or adapt this file on your site, include proper attribution.

- Recommended: a high-resolution PNG (transparent background) or SVG.
- After placing a local file, refresh the site; the faded background will appear automatically.

Local copy: A local copy of the Wikimedia image has been saved at `static/images/logo.png` for offline use.

Change faded logo size:

- To make the faded logo smaller, add `logo-small` to the `body` class: `<body class="cyberpunk logo-small">`.
- To make it larger, add `logo-large`: `<body class="cyberpunk logo-large">`.
- Default size is `logo-medium` (36%) — you can use `logo-medium` or omit any size class.
