Key Features

Advanced Security

Role-Based Access Control: Strict RBAC for Santa Fe Admin, Dispatcher, and Public Viewer roles

Brute-Force Protection: Django-Axes active defense against login attacks

Privacy & Masking

Field-Level Masking: Precise coordinates and contact info hidden from public users

Anti-IDOR Protection: Users only access incidents they reported or are assigned to

Inline Formsets

Incident Logging: Primary incident + multiple hazard images in one form

Advanced Filtering: Dashboard with date, status, and priority filtering

RESTful API

JWT Authentication: Secure token-based API access for mobile apps

API Documentation: Full Swagger/OpenAPI documentation available
